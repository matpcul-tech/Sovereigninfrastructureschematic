User Guide
◈ Overview

What Is Sovereign Markets?

Sovereign Markets is your personal AI-powered trading intelligence platform built under Sovereign Shield Technologies. It combines a Bloomberg Terminal aesthetic with real market data and an AI signal layer called Sovereign Signal. Think of it as a command center for active trading research -- not a broker, not a robo-advisor, but a professional-grade tool that puts live data, chart analysis, and AI interpretation in one place.

What It Covers
  • Real-time stock quotes and candlestick charts via Finnhub
  • Pre-market gapper scanner powered by Alpha Vantage
  • AI chart interpretation from Sovereign Signal (Claude)
  • Personal watchlist and trade journal stored in Supabase
  • Crypto-capable -- point it at BTC, ETH, any Binance symbol
⬡ Logging In

Getting Access

Sovereign Markets uses magic link authentication via Supabase. No password to remember.

Steps
  1. Navigate to the app URL
  2. Enter your email address on the login screen
  3. Click "Send Magic Link"
  4. Check your email and click the link -- it logs you in automatically
  5. Your session stays active until you sign out
Note

If you see an "expired magic link" error, just request a new one. Links expire after 24 hours.

◉ Chart

The Main Chart

The chart is your primary workspace. It pulls live OHLCV candlestick data from Finnhub and renders it in the Sovereign Shield dark theme.

Steps
  1. Type a ticker symbol in the search bar (e.g., AAPL, TSLA, SPY)
  2. Hit Enter or click the search icon to load the chart
  3. Use the timeframe buttons (1D, 5D, 1M, 3M, 1Y) to adjust the view
  4. Toggle indicators using the toolbar -- SMA, EMA, Volume, RSI, MACD are available
  5. Hover over any candle to see exact OHLCV values in the tooltip
Note

Finnhub free tier supports real-time quotes during market hours. After hours you will see the last closing price.

◈ Sovereign Signal

AI Chart Analysis

Sovereign Signal is the AI layer built on Claude. After you load a chart, it reads the price action and gives you a structured interpretation.

What It Covers
  • Trend direction -- uptrend, downtrend, or consolidation
  • Key support and resistance levels identified from recent price structure
  • Volume read -- is volume confirming or diverging from price?
  • Signal bias -- bullish, bearish, or neutral, with reasoning
  • What to watch -- specific conditions that would change the read
Note

Sovereign Signal gives chart interpretation, not trading advice. You make the call. This distinction is intentional and important.

⬡ Scanner

Pre-Market Gapper Scanner

The scanner runs every morning before market open and identifies stocks that gapped up or down significantly overnight. It is powered by Alpha Vantage.

Steps
  1. Click the "Scanner" tab in the top navigation
  2. The Gappers tab loads automatically with pre-market movers
  3. Filter by gap percentage using the slider (default shows 5%+)
  4. Click any ticker in the scanner list to load it in the main chart instantly
  5. The News tab shows market-moving headlines from Finnhub for context
Note

Alpha Vantage free tier allows 25 requests per day. If the scanner shows a data unavailable state, the daily limit was hit. The main chart and Sovereign Signal keep working regardless.

◉ Watchlist

Your Watchlist

The watchlist is your personal ticker list, stored in your Supabase account so it persists across sessions.

Steps
  1. Load any ticker in the main chart
  2. Click the bookmark icon or the "Add to Watchlist" button
  3. Access your list anytime from the Watchlist panel on the right sidebar
  4. Click any ticker in your watchlist to load it in the chart
  5. Remove tickers by hovering and clicking the X icon
◈ Trade Journal

Trade Journal

Log your trades and notes directly in the app. The journal is private to your account and stored securely in Supabase.

Steps
  1. Navigate to the "Journal" tab
  2. Click "New Entry" to log a trade or observation
  3. Fill in ticker, direction (long/short), entry/exit prices, and notes
  4. Save the entry -- it timestamps automatically
  5. Filter past entries by ticker or date range using the search bar
Note

The journal is a research and reflection tool. It does not connect to any brokerage or execute trades.

⬡ Crypto

Using Crypto Symbols

Sovereign Markets can pull crypto data using the Binance public API. No extra API key required.

What It Covers
  • Use Binance symbol format: BTCUSDT, ETHUSDT, SOLUSDT
  • Type the symbol in the chart search bar exactly as shown
  • Candlestick data and timeframes work the same as stocks
  • Sovereign Signal reads crypto charts the same way it reads equity charts
  • The scanner is equity-only -- crypto symbols do not appear there
◉ API Limits

Free Tier Limits to Know

The app runs on free API tiers during development. Here is what that means in practice.

What It Covers
  • Finnhub: Real-time quotes and candles -- generous free tier, the main chart almost never hits limits during normal use
  • Alpha Vantage: 25 requests per day -- the scanner may degrade late in the day if used heavily
  • Binance: Public endpoints, no key required, no meaningful limit
  • Claude (Sovereign Signal): Each signal call uses tokens, so avoid rapid repeated requests on the same chart
  • Supabase: Free tier supports up to 500MB storage and 50,000 monthly active users -- more than enough for personal use
